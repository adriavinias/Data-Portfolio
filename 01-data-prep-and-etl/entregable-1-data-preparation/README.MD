# Entregable 1: Data Preparation
## Context & Project Goal

The overall objective of this project is to process and prepare an automotive market dataset to support future predictive pricing and valuation models.

This phase focuses strictly on **Data Cleaning, Feature Engineering, and Data Preprocessing**, ensuring the raw dataset is transformed into a high-quality, production-ready format for downstream analytical and Machine Learning workflows.

### Key Focus Areas:
* **Data Quality & Cleaning:** Handling missing values, inconsistencies, duplicates, and outliers.
* **Feature Engineering & Transformation:** Normalization, categorical encoding, and feature scaling.
* **Dataset Readiness:** Exporting a clean, structured dataset optimized for predictive price modeling.

> **Note:** This section strictly covers the data processing pipeline and quality checks prior to the predictive modeling phase.
