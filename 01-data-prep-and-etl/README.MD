# Data Preparation, Pipeline Engineering & EDA

Welcome to the **Data Preparation & Exploratory Analysis** module. This folder contains projects focused on turning raw, unstructured, or messy datasets into high-quality, production-ready data pipelines for analytical and Machine Learning workflows.

---

### Core Competencies Demonstrated
* **Data Quality & Hygiene:** Handling missing values, structural inconsistencies, duplicate records, and extreme outliers.
* **Feature Engineering:** Categorical encoding (One-Hot, Target Encoding), feature scaling, and feature extraction.
* **SQL & Data Manipulation:** Complex queries utilizing Common Table Expressions (CTEs), Window Functions, and efficient relational joins.
* **Exploratory Data Analysis (EDA):** Uncovering initial distributions, variable relationships, and statistical properties prior to preprocessing.
