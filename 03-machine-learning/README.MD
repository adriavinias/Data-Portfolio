# Machine Learning & Predictive Modeling

This directory showcases applied **Supervised and Unsupervised Machine Learning** solutions designed to solve specific operational and commercial business problems.

---

### Core Competencies Demonstrated
* **Model Selection & Training:** Classification, Regression, and Clustering algorithms (Logistic Regression, Decision Trees, Random Forest, Gradient Boosting).
* **Evaluation & Optimization:** Metric selection (AUC-ROC, Recall, F1-Score, RMSE), cross-validation, and hyperparameter tuning (GridSearch / Optuna).
* **Class Imbalance Handling:** Applying techniques like SMOTE or threshold tuning to handle skewed target distributions.
* **Model Explainability:** Using SHAP values and feature importance analysis to interpret model predictions.

---

### Featured Projects

* **[MobileNOW Customer Churn & Propensity Scoring](./telecom-churn-prediction)** `[Python]` `[Scikit-Learn]` `[SHAP]`
  * **Objective:** Predict churn probability ($Churn=1$) for a cohort of 1,500 telecom customers to optimize a targeted telemarketing retention campaign.
  * **Key Outputs:** Risk-ranked customer propensity list and feature importance analysis identifying primary drivers of customer attrition.
